### 3-2. 계산식과 과세표준 (⚠️ 가장 중요한 디테일)
공식 PDF `[출처: https://doc.image-qoo10.jp/sqm/JP/guide_uriagekinseisankinoutiwake_KR.pdf, Update 2022-10, PDF 직접 파싱]` **확실**

```
販売手数料 = (상품금액 + 옵션금액 + 배송비) × 수수료율
```
- **옵션 추가금액과 유료 배송비에도 수수료가 붙습니다.** 즉 유료배송으로 돌리면 배송비까지 10%를 뗌
- 공식 예시: 판매가 2,000엔 + 옵션 120엔 + 배송비 380엔 → (2000+120+380)×10% = **250엔**

**과세표준은 「販売価格」(할인 전)이지 「決済金額」(할인 후)이 아님:**
> 원문: "판매수수료의 금액은 「판매가격」에 수수료율을 적용하여 계산합니다. **할인이 있을 시, 판매가격과 결제금액(할인적용후 금액)이 다르기에 주의** 부탁드립니다."

**확실**. 다만 정산 명세의 「수수료조정」 항목에서 **Qoo10 부담 상품할인 · 세트할인은 조정(공제)**됩니다. **셀러 부담 할인은 조정되지 않습니다.** `[동일 PDF]` **확실**

→ **할인 폭이 클수록 실효 수수료율이 명목보다 올라갑니다.** 20% 할인 판매 시 명목 10%는 실질 12.5%가 됩니다. Qoo10처럼 상시 할인 구조인 플랫폼에서 가격표를 설계할 때 핵심 변수입니다.

- **소비세 10%가 수수료에 별도 부과.** 공식 예시: 6,000엔 × 10% = 600엔(수수료), 600엔 × 10% = 60엔(소비세) → **합계 660엔**. `[출처: https://article-university.qoo10.jp/entry/54]` **확실**

### 3-9. 정산 명세 구조 (QSM > 정산관리 > 판매진행내역)

```
B. Qoo10서비스수수료 = 상품서비스수수료 + 배송비수수료 + 외부광고수수료 + 수수료조정

────────────────────────────────
E. 정산대금 = A − B − C − D
```

- 출점료·월정액 진짜 0엔. 성과보수형이라 초기 리스크 낮음

- 심사 대기 중에도 상품 셋업 가능 → 리드타임 압축 가능

**나쁜 것**
- 해외 계좌 + 해외 출하지 = **+2% 무조건**. 뷰티 10% → **12%**
- **수수료 과세표준이 할인 전 판매가** → 할인이 깊을수록 실효율 상승
