# Lane A5: Canada. K-beauty basic skincare, who buys, by community

Compiled 2026-09-09. Method: web search + page fetch only. READ = the claim was read on the fetched page. SNIPPET = seen only in a search-result snippet, page not fetched or not fetchable. Nothing is inferred from names or photos. Two sources are never merged into one row.

Headline: **no Canadian source assigns a community to a specific basic-skincare category** (toner pad, sunscreen, snail serum, etc.). Community evidence exists only at the "K-beauty overall" grain (NielsenIQ, The Guru, KOTRA) and at the channel grain (which stores in which neighbourhoods carry which categories). Category-by-community rows below are therefore channel signals, labelled as such.
